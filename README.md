# What Makes a VLA Reactive? A Study of Execution Strategies for Dynamic Manipulation

Project page for the CoRL 2026 Workshop (Efficient Foundation Models for Real-Time Embodied AI) paper by Zhuoyue Li, Zhendong Han, Pankhuri Vanjani, Wenting Li, and Rudolf Lioutikov
(Intuitive Robots Lab, KIT).

Built with the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
(`original-version` branch).

## Local preview

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Publishing (GitHub Pages)

Repository **Settings → Pages → Source: Deploy from a branch → `main` / root**.
The site will be served at `https://intuitive-robots.github.io/What-Makes-a-VLA-Reactive/`.
